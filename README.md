# 편히자 (sleep-comfortable)

버스·지하철 타며 졸 때, 내릴 곳 전에 깨워 주는 웹 서비스입니다.

화면(탭)을 켠 채로 졸면, 공공데이터로 고른 정류장·역에 가까워질 때 소리·진동으로 알립니다.

## 문제

통학할 때 자고 싶지만, 내릴 곳을 놓칠까 봐 깊게 못 잡니다. 타이머는 교통 상황에 따라 틀리고, 지도 알림은 설정이 많아 며칠 만에 꺼집니다. 지하철은 지하에서 GPS가 잘 안 잡힙니다.

편히자는 버튼을 적게 두고, **고른 정류장/역 전에 깨우는 일**만 합니다.

## MVP 범위 (3주)

이번 버전은 아래를 약속합니다.

- 버스와 지하철
- 탭을 켠 상태
- 공공데이터로 내릴 정류장·역을 검색
- 버스: GPS와 정류장 좌표 거리로 깨우기
- 지하철: 탑승역→도착역 남은 정거장으로 깨우기. GPS가 되면 역 좌표도 사용

화면을 끈 상태, 백그라운드 알림, 환승 이어 감시는 이번 범위가 아닙니다.

## 기능

| 우선순위 | 기능 | 설명 | 이유 |
|----------|------|------|------|
| Must | 하차 직전 깨우기 | 내릴 정류장/역 전에 소리·진동. 버스는 GPS, 지하철은 남은 정거장 | 없으면 서비스가 아니다. 본체는 깨우기 하나다. |
| Should | 내릴 곳 검색 | 공공데이터로 버스 정류장·지하철역 검색 | Must를 쓰려면 내릴 곳을 골라야 한다. |
| Should | 알림 끄기 | 깨운 뒤 소리·감시를 한 번에 종료 | 알람이 남으면 다음부터 안 켠다. |
| Should | 자주 가는 곳 | 학교·집을 저장해 두고 원탭으로 감시 시작 | 탈 때마다 검색하면 이탈한다. |
| Could | 지금 여기 저장 | 검색이 안 될 때 현재 위치를 목적지로 | 검색이 되면 없어도 된다. |
| Could | 실시간 도착정보 | 목적지 역 도착 시각 참고 | 없어도 깨울 수 있다. |
| Won't | 화면 꺼도 알림 | 웹만으로 잠금 화면 위치를 믿기 어려움 | |
| Won't | 환승 이어 감시 | 버스 한 번 또는 지하철 한 번만 | |

## 사용 흐름

1. **내릴 곳** — 버스/지하철을 고르고, 공공데이터로 내릴 곳을 검색. 지하철이면 탑승역도 고름. 또는 저장된 학교/집
2. **감시 중** — 탭을 켠 채로 이동. 버스는 남은 거리, 지하철은 남은 정거장. 중지하면 1번으로
3. **깨움** — 근처면 소리·진동. 확인을 누르면 감시 종료 후 1번으로

## 기술 스택

| 구분 | 선택 | 이유 |
|------|------|------|
| 화면 | React + Vite | 화면 3개 SPA |
| 위치·알림 | 브라우저 API | Geolocation, Wake Lock, Vibration, Web Audio |
| 정류장/역 | 무료 공공데이터 | 키는 Firebase Functions에 둠 |
| 백엔드 | Firebase Auth + Firestore | 익명 로그인, 학교/집 저장 |
| 배포 | Vercel | 정적 React 앱 |

자주 가는 곳(학교/집)은 로그인 화면 없이 익명 계정으로 Firestore에 저장됩니다.

## 로컬 실행

```bash
cd sleep-comfortable
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 이 열립니다.

폰에서 쓰려면 위치 권한을 허용하고, **탭을 켠 채**로 두세요.

- 버스: 정류장을 검색하거나 내 근처에서 고른 뒤 감시 시작
- 지하철: 내릴 역 → 타는 역을 고르면 1정거장 전에 깨움
- 학교/집으로 저장하면 다음에 한 번에 감시 시작

지하철역은 서울교통공사 노선별 지하철역 정보(공공데이터)를 앱에 넣었습니다. 버스 정류장은 서울시·경기도 버스정류소 위치정보(공공데이터)로 검색합니다.
